# Portfolio Website — Assignment 2 (Interactive Features)

## Project Description

My personal portfolio website is built with plain HTML, CSS, and JavaScript. Assignment 2 builds on [Assignment 1](https://github.com/s202340310/202340310-ABDALLAH_ALMOGBEL-assignment1) by adding saved theme preferences, project filtering and search, contact-form validation, and interface feedback and animations.

## Features Added in Assignment 2

| Requirement | Feature | Status |
|---|---|---|
| Dynamic content | Project category filters and live search | Implemented |
| Data handling | Theme preference saved with `localStorage` | Implemented|
| Data handling (extra) | Contact form validation and confirmation | Implemented  |
| Animation / transitions | Theme transition, project hover effect, and reveal animation | Implemented |
| Error handling / feedback | Field errors, form status, and “No projects match” empty state | Implemented  |
| AI enhancement | AI usage report and evidence | Completed |


## Setup Instructions (Run Locally)

No installation or build tools are needed.

1. Clone this repository:
   ```
   git clone https://github.com/s202340310/202340310-ABDALLAH-ALMOGBEL-assignment2.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser (or use the VS Code "Live Server" extension).
